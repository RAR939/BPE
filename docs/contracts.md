# Контракты движка процессов

Предлагаемые контракты для совместной реализации. Сейчас реализован только `GET /health` с ответом `{"status":"ok"}`.

## Определение процесса

Редактор публикует BPMN XML и настройки элементов по BPMN ID. Сервер проверяет их соответствие и строит граф исполнения. Каждая опубликованная версия неизменяема. Экземпляр хранит ключ и номер версии, а интерфейс загружает XML по этой паре.

Поддерживаем стартовые и конечные события, пользовательские и автоматические задачи, последовательные переходы, условные развилки с выходом по умолчанию и парные параллельные шлюзы. Граф первой версии ациклический. Метаданные пользовательской задачи содержат `assigneeId`, автоматической — `actionKey`. Простое условие содержит имя поля или путь к результату шага, оператор сравнения и значение. Группа `all` требует выполнения всех входящих в неё простых условий. Пример находится в `demo/definitions`.

## Состояние и повторные команды

Снимок экземпляра содержит статус, входные данные, результаты шагов по ID узла, токены, задачи, историю, результаты обработанных команд и ожидающие действия. Статусы — `Running`, `Paused`, `Completed`, `Cancelled` и `Failed`. Параллельный шлюз объединения выпускает один токен после прибытия всех ожидаемых веток.

Сохранение перехода условно по ревизии. При конфликте обработчик загружает актуальный снимок и повторно проверяет применимость команды. Изменяющий запрос принимает `commandId`; повтор запроса возвращает сохранённый результат. Для повторов внешнего вызова используется стабильный ID задания. Пауза удерживает обработанный результат до возобновления. Отмена закрывает открытые задачи и прекращает продвижение экземпляра.

Участники, отвечающие за API и хранилище, согласуют способ условной записи с командой метаграфовой платформы.

## Маршруты API

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/definitions/{key}/versions` | Опубликовать BPMN XML и настройки. |
| `GET /api/definitions` | Список определений и последних версий. |
| `GET /api/definitions/{key}/versions/{version}` | XML и настройки конкретной версии. |
| `POST /api/instances` | Запустить указанную версию с входными данными. |
| `GET /api/instances/{id}` | Статус, версия и массив `activeNodeIds`. |
| `GET /api/instances/{id}/history` | Упорядоченная история переходов. |
| `GET /api/tasks?assigneeId=…` | Задачи исполнителя. |
| `POST /api/tasks/{id}/complete` | Завершить задачу с результатом. |
| `POST /api/instances/{id}/pause` | Приостановить экземпляр. |
| `POST /api/instances/{id}/resume` | Возобновить экземпляр. |
| `POST /api/instances/{id}/cancel` | Отменить экземпляр. |
| `GET /health` | Проверить доступность API. |

Ошибки возвращаются в формате `ProblemDetails`. Ошибки определения содержат BPMN ID, если проблема относится к конкретному элементу.
