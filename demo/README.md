# Согласование заявки на кафедре

Схема `definitions/department-approval.bpmn` и настройки `definitions/department-approval.json` составляют пример определения процесса.

1. Студент отправляет заявку с данными из `data/requests.json`.
2. Автоматическая проверка возвращает поле `valid`. При ошибке процесс завершается отказом.
3. При корректной заявке секретарь и руководитель получают две независимые задачи. Каждый передаёт поле `approved`.
4. После обеих проверок процесс завершается одобрением, если оба сотрудника согласны. Иначе он завершается отказом.

Каталог `test-service` предназначен для тестового HTTP-сервиса, который будет выполнять автоматическую проверку.
